# merge-queue-probe

Throwaway probe repository for GitHub Merge Queue behaviour.

It exists to answer questions that cannot be answered from documentation or
mocks: what the `merge_group` event payload actually contains, whether the
Actions `GITHUB_TOKEN` can read `repository.mergeQueue` over GraphQL, and how
merge-group commits map back to their source pull requests.

Nothing here is real. Do not add scenario data, personal information, email
addresses, tokens, secrets, or anything copied from another repository.
Dummy README text, probe workflows, and throwaway pull requests only.
